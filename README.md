# Boykisser Texture Pack

A Boykisser-themed texture pack for Geometry Dash 2.2. It is made from edited images, with many sprites reshaped and almost every button is recoloured or has its own Boykisser style.

**I made almost all of it by myself.**

## Installation
**Shown steps are designed for Windows systems, however it doesn't change much on other systems**

Installing the File
1. Go to the releases tab: https://github.com/SzczupakUser/Boykisser_Texture_pack/releases
2. Choose your game version
3. Download the .zip file

There are 2 main methods to implement the texture pack in your game:
1. By installing **Geode**, and **Texture loader** mod for gd (**recommended**)
2. Doing it manually by placing the files in the game’s Resources folder (**fast, no mods needed**)

### Adding it manually
- Go to your files and unzip the folder (right-click and extract). You should get a new folder
- Go to steam and tab library
  <details><summary>Screenshot</summary><img width="1271" height="795" alt="L" src="https://github.com/user-attachments/assets/8513ef90-2655-4a39-98f7-260207defd87" /></details>
- right-click geometry dash and hover over manage and click browse local files
  <details><summary>Screenshot</summary><img width="468" height="322" alt="M" src="https://github.com/user-attachments/assets/c4dd2624-9e62-4c0a-aa98-b6f968c901a7" /></details>
- Open resources folder and copy contents of the pack inside. Choose the replace option for the files once copied
- The texture pack is implemented correctly! Open the game to see it

**If you want to undo the changes just click "Verify integrity of game files" in the game properties (right-click game -> Properties -> Installed Files -> Verify integrity of game files)**

### Possible bugs
If your icon is not in white color the boykisser image on the icon will be in the same color, so if you want the original just use white icon color (You get it by completing Time Machine on practice mode)
